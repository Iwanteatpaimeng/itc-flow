面向华为 ICT 学院的 Edge Manifest V3 插件。无构建依赖、无远程脚本，设置与运行记录保存在当前浏览器。

## 安装

1. 使用 Edge 120 或更新版本，打开 `edge://extensions`，开启“开发人员模式”。
2. 选择“加载解压缩的扩展”，选择包含 `manifest.json` 的目录。可直接选择本项目目录，也可解压 `dist/itc-flow-edge-1.2.14.zip` 后选择解压目录；不能直接选择 ZIP 文件。
3. 在工具栏固定“ITC 学习助手 · Flow”。
4. 打开并登录华为 ICT 学院，进入具体课时页面，展开课程目录。
5. 打开插件，点击“开始学习”，允许访问当前课程网站。此后关闭插件面板，课程仍会继续处理。

## 使用

- 将当前课程任务作为完整页面处理，按文字、视频、后续文字与视频在页面中的顺序继续。
- 文本 / 文档设置的是**滚动间隔**，默认 10 秒，可设 1–3600 秒。每次等待在基准间隔上随机浮动 ±10%，例如 10 秒对应约 9–11 秒，然后向下滚动一小段正文或实际阅读容器。首次滚动也使用该间隔；修改设置会重新按新间隔等待。
- “开始学习”与进入新任务时先回到课程内容顶部，按间隔逐段向下滚动文字；遇到视频，停在课程阅读区域中间播放。独立课程面板只滚动面板，面板到底后不转而滚动外层网页；开始或重新开始也只重置课程区域。**视频结束后继续当前页下方的文字和后续视频，不会直接切换任务。**每段视频在本轮处理一次；独立滚动阅读区也按页面顺序处理。
- 视频默认静音。浏览器阻止播放时，可在播放器中点击播放；暂停 / 停止会暂停视频，停止或切换时恢复原静音设置。内嵌内容只在滚到相应位置后交给子页面处理，处理结束返回原页面继续向下。
- **页面内容走完、所有视频处理完，且平台显示当前任务已完成**，才默认等待 3 秒进入下一项。等待可设 0–30 秒；关闭“自动进入下一项”后停在当前任务。不按经过时长、单个视频结束或滚到底推断任务完成。
- 到底后没有识别到平台完成标记时，显示“等待平台确认”。可在“网站适配”填写仅在当前任务已完成时匹配的 CSS 选择器，或手动切换；插件不写入或伪造平台完成状态。
- “暂停”同时暂停滚动、居中调整和当前视频；“继续”恢复；“停止”结束本次处理。暂停期间选择其他课时，再继续会识别新课时。
- “重新识别”用于页面加载完成、手动切换任务或调整网站适配后重新连接。新一轮“开始”会清空本轮计数；暂停 / 继续保留计数。
- “重新开始”清空本轮记录、已播放片段与待执行跳转，**回到当前任务顶部**，视频从头重新处理。“继续”保留当前页位置和已播放片段。手动换页后重新识别新任务；旧任务的迟到事件不会影响新任务。
- 工具栏主题按钮在跟随浏览器、亮色、暗色间循环；也可在设置中选择。设置面板从触发按钮位置展开，按钮提供轻微弹性反馈，尊重浏览器“减少动态效果”偏好。
- 运行中或已暂停的会话在同一浏览器会话内保留；同源页面刷新会重新识别。关闭课程标签页或退出浏览器后，需要重新开始。

## 网站适配

### 1.2.14 内嵌课件域名改为安装即授权

- 真实课程里的 Word 会先落到 `urc.hep.com.cn`，再套一层 `office-cn-beijing.imm.aliyuncs.com` 渲染。此前这两个域名只在运行时按需申请，没点“连接内嵌内容”就永远注入不了，表现是正文读完视频、滚到 Word 位置后一直停在“正在连接内嵌内容”，诊断里这两个框架始终是 `permission: false, no_receiver`。
- 现在 `urc.hep.com.cn` 与 `*.imm.aliyuncs.com` 写进 `host_permissions`，安装/重载扩展时即生效，不需要再手动点授权；其他站点仍走按需申请。
- 兜底：同一个内嵌文档连续 4 次都连不上（例如页面侧禁止嵌入或加载失败）时不再无限等待，把它记为已处理并继续后文，诊断里能看到 `release-giveup`，任务不会整体卡死。
- 更新后在 `edge://extensions` 重新加载扩展，刷新课程页再点“开始”；已授权的话诊断里这两个框架会变成 `permission: true` 并出现子引擎。

### 1.2.13 只把阅读任务交给真正装有正文的框架

- 课程页有三层框架（`e.huawei.com` → `application-learn` → `course-reader`）。此前只要外层框架“检测到一个内嵌页面”就会被当成正文，任务可能被派给一个自己没有文字、也没有视频的壳，表现就是点了开始什么都不动、视频也不播放。现在仅用于承载内嵌页面的壳排在真实阅读器之后，任务一定落到带正文/播放器的那一层。
- 识别诊断的 `runtime.trace` 增加 `run` 起点：如果诊断里 `phase` 是 `idle`、`trace` 为空，说明这一次根本没有启动任务（通常是刚重载扩展、页面还没重新开始），而不是引擎卡住。
- 按 1.2.12 诊断里的真实几何（滚动区 5961px、三章 4400 + 170 + 1256、停在 3965）补了用例：视频在阅读区下方 250px 时也能滚到、居中、起播，播完继续后文。
- 更新后在 `edge://extensions` 重新加载扩展，刷新课程页，再点“开始”。

### 1.2.12 从当前章节开始并解释每一步阅读决定

- 数字教材把整本书的章节放在同一个滚动容器里，此前“开始 / 重新开始”会把容器滚回顶部，看起来总是从第 1 章读起。现在以当前阅读区域里正在显示的那一章为锚点重算滚动位置，只重新播放本章内的视频，不再回到全书开头。
- 折叠播放器（视频被 `overflow: clip` 的零高度容器包着）会让阅读端口的高度算成 0，导致早已滚到视口上方的视频仍被当成“下一个待处理媒体”，任务停在“课程区域已无可继续向下滚动的空间”。现在端口退化时回退到阅读区根端口，已经越过的视频不再拦截后文。
- 识别诊断新增 `runtime.trace`（最多 16 条、只含阶段、动作、滚动位置与框架 id），用来在真实页面上复盘每一次“滚动 / 起播 / 委托 / 阻塞”的决定，不含地址、token 或文本内容。
- 本地按真实诊断的几何尺寸（滚动区 664/2131、章节 1256 + 760、播放器在 258）验证了“视频在章节前段能被播完再继续”，以及“从所选章节开始重启”。
- 更新后在 `edge://extensions` 重新加载扩展，再刷新课程页；若仍不播放，复制识别诊断后 `runtime.trace` 会直接指出卡在哪一步。

### 1.2.11 内嵌 Word 连续滚动与播放器播完再继续

- 正文里最后一个内嵌 Word / 播放器永远无法精确居中到阅读区域中间，此前会停在“无可继续向下滚动的空间”。现在滚到本章底部后，只要该框架在阅读区域内可见，就把它当作一个独立的阅读步骤交给它自己的引擎，仍按正文的方式逐段滚动，读完再回到外层后文。
- 内嵌播放器（独立 iframe 里的视频）同样按这个步骤处理：由该框架自己的引擎居中、静音起播，播完才算这一步完成，之后外层才继续正文，不会提前跳过视频。
- 内嵌内容未授权或子页面还没响应时，外层不再永久冻结：按 4 秒、8 秒、16 秒、30 秒的间隔自动重试连接，阅读位置保持不变；点“连接内嵌内容”授权后，同一次任务里会自动接上并继续，不必重启正文。
- 已经播完却被滚出视口的视频不再让任务卡在“无法居中”，会直接记为已播放并继续后文，不会重播。
- 自动重试只对有归属的内嵌内容生效，不会每秒向页面重复申请权限；暂停、停止时同时取消等待中的重连。
- 更新后在 `edge://extensions` 重新加载扩展，再刷新课程页。

### 1.2.10 重定向文档按实际来源授权

- 内嵌 Word 常先加载 `src` 指向的地址再重定向到真实文档域名。此前按 `src` 主机校验，重定向后既连不上子页面、也不会提示授权。现在以实际渲染的文档框架为准：沿当前正文框架逐层枚举真实子页面来源，只按这些来源申请权限，不再信任 `src` 主机。
- 未授权时不注入、不改变阅读位置，弹窗“连接内嵌内容”列出真实文档域名；同一任务内暂停、继续不会丢失这些待连接来源，完成后重新识别才清空。
- 授权后只注入该任务文档链的直接子框架，嵌套的 Word / Office 阅读器仍由上一层逐层委托；同页无关的外层组件不会被注入或探测。
- 识别诊断把重定向后的最终框架仍归到原正文框架的待连接请求，只显示来源域名与层级，不包含 token、签名或查询参数。
- 本地多层跨域验证覆盖了“声明来源与实际来源不同”“授权后重连”“暂停保留来源”“诊断不漏凭据”四类流程；真实平台的最终重定向来源以诊断中的实际框架为准。
- 更新后在 `edge://extensions` 重新加载扩展，再刷新课程页；若显示“连接内嵌内容”，点击并允许诊断中列出的真实域名后继续。

### 1.2.9 Word 接管连接与独立滚动组件

- 根据 1.2.8 诊断，教材已滚动 15 次并交出控制，但 Word 来源 `dbook.hep.com.cn` 没有子页面响应。修复已授权 Word 懒加载、接收脚本晚于首次绑定就绪时的连接缺口：只注入当前正文所属的真实文档子页面，沿用原绑定重试，不重启正文。尚未授权时仍需点击“连接内嵌内容”并允许。
- 绑定后的 Word 支持画布渲染层与独立窄滚动条互为兄弟的布局；只在邻近文档区域内匹配，不用目录或文档大纲作为正文证据。文档读完返回原教材位置继续下方文字。
- 修复缩放阅读面板中视觉坐标直接用于 `scrollTop` 而越过文档居中接管点的问题。
- 诊断只读枚举实际框架，补充来源、权限、是否已连接及等待中的所属关系，未响应的 Word 不再直接消失。
- 本地多层跨域验证中，7px 内层滚动组件推进至 1486/1486，教材在文档期间固定于 360px，之后继续至 820/820；外层网页保持 149px。真实 Word 内部 DOM 尚未获得，不能把本地验证等同于线上已确认。
- 更新后在 `edge://extensions` 重新加载扩展，再刷新课程页。打开插件；若显示“连接内嵌内容”，点击并允许 `dbook.hep.com.cn`，再继续或重新识别。

### 1.2.8 修正目录与正文滚动目标

- 修复 1.2.7 新增的通用内嵌文档识别抢在正文前面、把左侧目录当成文档的问题。优先采用已识别的教材正文和真实阅读器，Word 兜底只用于未识别出正文的内嵌页面。
- 排除普通 DIV 实现的教材目录、树形目录和文档大纲；目录里的文字、图标与缩略图也不能作为祖先容器的正文证据。开始、重新开始和读到底都不滚动目录。
- 保留正文 → Word 内部 → 后续正文的顺序。Word 在画布、文本和文档阅读器之间切换时保留同一任务身份和阅读位置。
- 新增左目录 / 右正文的真实 iframe 验证页，并用已发布 1.2.7 复现误选目录，再验证修复后的选择、开始、重启及到底边界。
- 更新后重新加载扩展并刷新课程页面，清除旧版已选错滚动目标的会话；权限与设置保持原样。

### 1.2.7 嵌套 Word 文档连续阅读

- 按正文顺序滚到 Word 后，停住教材阅读器，连接 Word 内部的实际滚动组件；文档读到底后返回原教材位置，继续下方文字，不重新开始当前章节。
- Word 尚未回报状态时也保存它的续读标识；暂停、继续和重新识别先保存当前快照，避免把继续误当成重新开始。文档 iframe 加载或更新地址时仅重新连接该文档，保持教材任务标识与位置。
- 支持常见 Word / DOCX 阅读区域，以及由图片或画布呈现、具有独立滚动组件的内嵌文档。文档加载时显示“加载文档”，不把加载占位内容当成已读完。
- 未授权的 `dbook.hep.com.cn` 等内嵌来源显示“连接内嵌内容”；点击并允许后从当前位置继续。新增 `webNavigation` 权限只用于在当前课程页定位嵌入框架，让已获授权的 Word 能在其他未授权框架存在时连接成功。
- 已通过本地跨域、多层嵌套、文字与画布文档、加载等待、暂停继续及地址更新验证。用户诊断尚不包含真实 Word 子页面的内部结构；若授权后仍无法滚动，请复制新诊断以检查实际组件。
- 更新后在扩展页重新加载插件，并刷新课程页面以替换旧脚本。仍只滚动真实内层阅读器，保留真实倒计时和平台完成确认。

### 1.2.6 连续教材章节衔接

- 同一个 `#reader-container` 内的当前章、下一章以及随滚动更新的章节菜单属于同一轮阅读。前章节点回收时重新绑定正文节点，保留滚动位置、倒计时、运行标识和已播放记录，避免从头开始。
- 章节短暂空白或正在加载时保留进度等待，不把空白当成整项被替换或内容完成。新章加载后继续原有阅读流程。
- 多层内嵌阅读器等待连接时，重新识别不再重新启动整条委托链；实际切换课程或路由仍隔离旧任务。
- 数字教材视频用章节标识和视频标识保留完成记录；章节重新渲染、临时媒体地址变化不会重播已完成视频。播放器节点替换时退役旧监听，播放结束仍恢复阅读计时。
- 保留 1.2.5 的内层滚动边界，不移动外层网页。更新后重新加载扩展并刷新课程页面，新版本会暂停旧会话以应用新的任务标识规则。

### 1.2.5 数字教材只滚动内层阅读器

- 取消数字教材视频授权时移动祖先网页的行为。视频按 `#reader-container` 投影到浏览器中的实际可见范围居中；外层网页与中间框架保留原位置。
- 只承载 iframe 的课程外壳直接连接可见教材，无需整个 iframe 居中。外壳不可滚动时仍可启动内层阅读器；开始与重新开始不重置外壳滚动位置。
- 数字教材宿主优先于正文内的代码块和局部自定义滚动条；运行与识别诊断均使用真实教材滚动组件。
- 每次实际滚动前确认教材仍可见；屏外或折叠裁剪时停止阅读，恢复可见后继续。末尾被外层窗口遮挡时提示手动显示完整教材，不提前返回完成。
- 保留逐段文字、按顺序展开视频、播放后继续同页文字和真实倒计时。增加正常可见、屏外、部分裁剪、缩放、重新开始及无滚动空间中间框架的回归验证。

### 1.2.4 嵌套教材展开后播放与计时转发

- 当时尝试让祖先按实际播放器位置重新对齐，但该做法仍会移动外层网页，已由 1.2.5 的内层可见阅读区方案替换。
- 修复外层使用自己已停止的计时器，导致插件显示 `--:--` 的问题。多层委托逐级转发当前阅读器的真实倒计时、滚动次数和展开状态；暂停后停止计时，过期会话与错误连接标识不能覆盖当前进度。
- 折叠视频仍按顺序滚到标题后点击展开，再小步移到阅读区中间播放；播放结束继续同页文字。展开、连接、等待滚动与受阻状态分别提示，不编造剩余秒数。
- 增加脱敏运行状态与媒体几何诊断，便于区分未展开、未居中、播放未获授权和计时器中断。
- 本地验证增加真实 `owner → middle → reader` 委托流程，并将真实阅读器状态接入插件弹窗；此前仅祖先探测模式不能覆盖这条流程。

### 1.2.3 桌面教材视频衔接与实时秒数

- 根据用户的 Edge 诊断适配桌面版 `etextbook-reader-web` / `.reader-web`，识别 `#reader-container` 内的正文与兄弟视频；兼容此前的手机版结构。
- 修复视频延迟展开后已触发的计时器句柄未清除、导致不再滚动的问题。展开成功会启动新的滚动间隔，展开失败则保留当前位置并提示操作。
- 修复多层内嵌页面中 BODY 滚动传播到浏览器视口时误滚 BODY 的问题；播放仍须确认视频位于实际可见阅读区域中间。

已实现面向 ICT 学院常见课程结构的识别规则，并兼容 Element / Ant 树形目录、普通课时清单、HTML5 视频、PDF.js 和文档嵌入容器。已在这门数字教材的登录页面检查 DOM，并以实际滚动和点击确认内层阅读器、视频折叠结构；插件运行通过本地同结构页面验证。未在真实平台自动跑完整课程，不同地区、课程与平台版本可能需要调整选择器。

若提示正在识别，请确认进入了具体课时，并等待页面加载；然后在“学习设置 → 网站适配”填写页面对应的 CSS 选择器：

| 设置 | 对应元素 | 示例（需以实际网页为准） |
| --- | --- | --- |

| 实际滚动容器 | 包住正文、实际发生滚动的组件；留空自动识别 | 数字教材桌面版 / 手机版：`#reader-container` |

若页面包含其他域名的文档或播放器，插件会显示“连接内嵌内容”。点击后仅申请当前可见内嵌页面的域名权限，随后保留阅读位置重新连接。没有授权的跨域页面不能读取或控制。

这门数字教材默认无需手填。若之前填过外层正文或面板选择器，请清空旧覆盖项后保存并重新开始。需要手动指定时，“正文 / 文档区域”可填 `#reader-container .reader-chapter-content.w-e-text`，“实际滚动容器”填 `#reader-container`；二者不要混填。

默认完成识别限定当前选中任务的明确完成属性 / 样式，以及当前内容中的任务完成属性。不同版本平台的标记可能不同；自定义完成选择器不能填写恒存在的容器、普通“下一项”按钮或其他课时的完成图标。

浏览器内置 PDF 阅读器、封闭 Shadow DOM、非 HTML5 / 专用加密播放器可能无法滚动或播放；在 PDF.js、网页正文和普通 HTML5 视频中可直接工作。课程目录未展开、下一按钮不存在或切换没有生效时，会显示原因并停止自动跳转。考试、测验、实验等任务需要手动处理。

插件通过页面正常的播放、滚动与点击行为操作，课程是否判定完成仍由平台决定。运行时保留课程标签页；Edge 的休眠标签页、节能模式或页面被丢弃可能中断播放和脚本，可将正在学习的网站加入“始终保持这些站点处于活动状态”。

## 权限与数据

- `activeTab` / `scripting`：在你点击开始后识别与操作课程页面。
- `storage`：保存设置、当前标签页的运行检查点和最近处理记录。
- `alarms`：在后台恢复任务切换与连接检查。
- 网站访问权限为可选项，安装时不获取所有网页内容；点击开始时申请当前网站，内嵌页面按需单独申请。离开启动时的网站会停止处理。
- 无账号密码读取、无数据上传、无第三方依赖。设置存于 `storage.local`；本轮任务与记录存于 `storage.session`，随浏览器会话结束清除。
