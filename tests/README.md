# 本地验证

运行 `npm test` 执行无第三方依赖的 Node.js 回归测试。

运行 `npm run fixture` 后，打开 <http://127.0.0.1:8765/tests/fixtures/course.html>。
该页面完全本地运行，包含可滚动文本、真实 HTML5 视频、文档阅读器以及需人工处理的章节测验。
视频使用 Canvas 和 MediaRecorder 在浏览器内生成约 3 秒的静音 WebM，无需外部媒体资源。

无需安装扩展即可验证界面和实际内容脚本：

- <http://127.0.0.1:8765/tests/fixtures/catalog-reader.html?mode=textbook>：真实 iframe 内左目录、右正文独立滚动，点击“开始正文验证”。目录保持 180px，外页保持 149px，正文滚动到底后返回；`mode=plain` 验证常规正文。支持暂停、继续与重新开始，结果显示在顶部状态栏。
- <http://127.0.0.1:8765/tests/popup-preview.html>：真实弹窗界面配合开发用 Chrome API 模拟器，可点击开始、暂停、主题和设置。
- <http://127.0.0.1:8765/tests/engine-preview.html>：真实 `content.js` 配合可见控制栏，可观察滚动间隔、真实视频事件、自动切换和完成历史。
- <http://127.0.0.1:8765/tests/fixtures/frame-preview.html>：真实父/子框架内容脚本，点击“从顶部开始”检查父页前文、内嵌视频、返回父页尾文和平台完成门槛。
- <http://127.0.0.1:8765/tests/fixtures/panel-course.html>：外页与右侧课程面板都可滚动，开始时只把面板归顶；检查外页始终保持 180px，视频在面板可见中心播放，尾文到底后等待完成信号。固定按钮支持暂停、继续和重新开始。
- <http://127.0.0.1:8765/tests/fixtures/embedded-word.html?cross=1&nested=1>：正文 → 跨域 Word → Word 内部阅读器 → 正文尾文。检查外页保持 149px、Word 内部阅读期间教材不动、返回后继续尾文，且 owner RUN 保持 1。可加 `variant=canvas&delay=10000` 检查画布和加载等待；“进入 Word 时刷新临时地址一次”检查重连，暂停 / 继续与重新开始分别保留和重置进度。

弹窗预览支持 `?phase=reading&theme=dark` 等参数以展示不同状态。预览模拟器只存在于 `tests/`，实际扩展使用真实浏览器 API。

在此页面启动扩展，将滚动间隔设为 1 秒可快速观察向下滚动。文本/文档不因时间或到底自动完成；点击“正文滚到底”可检查底部等待，视频结束后仍应继续当前页，等待平台完成信号。
在开始视频之前点击“将视频移到屏幕下方”，可检查先居中再播放；居中期间暂停或停止应取消后续播放。
选择第 4 项“图文课程：先读正文再看演示”，检查先逐段滚动前置正文，再在视频自然进入中间时播放；整个过程不应直接跳到下方视频。
选择第 5 项可验证“前置文字 → 视频 1 → 夹心文字 → 视频 2 → 尾部文字”。日志会记录文字区域经过屏幕中间以及两次真实视频结束；视频结束不代表当前任务完成。开启“模拟平台确认当前任务已完成”，也必须等本页内容走完后才允许自动下一项。
“复用正文手动换页”会保留同一个 reader 元素及目录任务 ID，同时修改正文、标题和路由；“重新开始”会清空本地会话进度、已播视频记录并回到当前任务顶部。“继续”保留暂停位置与已播记录。
页面下方日志会记录真实滚动、video play/pause/ended 和“下一项”点击，便于检查是否重复切换。
也可以在阅读中暂停、关闭并重新打开扩展面板、手动切换目录，以检查会话是否正确恢复。

`tests/` 和 `package.json` 属于开发工具，不应包含在发布扩展的压缩包中。
